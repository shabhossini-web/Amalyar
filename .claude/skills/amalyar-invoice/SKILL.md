# فاکتور — عمل‌یار

> **وضعیت: هنوز ساخته نشده.** عمل‌یار الان ماژولِ فاکتور ندارد. این اسکیل نقشهٔ
> ساختِ آن است تا وقتی ساخته شد از روزِ اول با قوانینِ قفل‌شدهٔ پروژه بخواند —
> نه اینکه بعداً بازنویسی شود. منطقِ کسب‌وکار مرجعِ ملک‌طب (`invoice.html`)
> فقط **مرجع** است، نه کپی.

---

## ۱. ساختِ ماژول — چک‌لیستِ برشِ عمودی

ماژولِ فاکتور یک ماژولِ عادیِ عمل‌یار است، پس دقیقاً چک‌لیستِ قانونِ ۴ را دارد
(جزئیات در اسکیلِ `amalyar-standard` §۱):

1. **بک‌اند**
   - `features.service.ts` → `FEATURE_DEFAULTS.invoices = { minLevel: 4 }`
   - `server/src/invoices/` با `@Controller('invoices')` +
     `@UseGuards(JwtAuthGuard, FeatureGuard)` + `@Feature('invoices')`
   - مدلِ پریزما: `Invoice` با رابطه به `Visit`، و `InvoiceLine` برای سطرهای خدمت.
     تغییرِ schema → `migrate diff` با shadow-db → پوشهٔ migration.
   - **همهٔ مبالغ تومانِ صحیح** (قانون ۱۳). هیچ فیلدِ ریالی ساخته نشود.
   - **جمع‌ها فقط در `enrich()` سرور** (قانون ۱۵): `lineTotal`, `subtotal`,
     `grandTotal`, `amountInWords` — کلاینت هیچ ضرب و جمعی ندارد.
2. **فرانت**
   - `Users.jsx` → `FEATURE_FA.invoices = 'فاکتورها'`
   - `Launcher.jsx` → آیتم با آیکونِ SVGِ خطی + `min` fallback + `to:'/app/invoices'`
   - `src/app/Invoices.jsx` با اسکلتِ استانداردِ صفحهٔ /app + route داخلِ `<Protected>`
3. **تست e2e** — گیتِ سطح + ساختِ فاکتور + خروجیِ چاپ

## ۲. فرمولِ محاسبه

هر سطرِ خدمت دو سهم دارد (جراحی / فنی) و هر سهم مستقل حساب می‌شود:

```
جمعِ سطر = ضریبِ تعرفه × ساعت × مبلغِ واحد
جمعِ کل  = مجموعِ همهٔ سطرها
```

ساختارِ داده در سرور:

```ts
// server/src/invoices/invoices.service.ts
function enrichLine(l: any) {
  return {
    ...l,
    surgeryTotal: Math.round(l.surgeryCoeff * l.surgeryHours * l.surgeryUnit),
    techTotal: Math.round(l.techCoeff * l.techHours * l.techUnit),
    get lineTotal() { return this.surgeryTotal + this.techTotal; },
  };
}
```

> `Math.round` **فقط** این‌جا مجاز است. اگر در JSX دیدی، باگ است.

**خدماتِ پایه (مرجعِ ملک‌طب — مقدارِ اولیه، نه ثابتِ کد):**

| کد مراقبت | خدمت |
|---|---|
| ۹-۱۳۷۵ | EMG |
| ۹-۱۳۹۰ | EMG |
| ۹-۱۳۷۵ | MEP |
| ۹-۱۳۲۰ | SEP |
| ۹-۱۳۲۰ | VEP |
| ۹-۱۳۰۰ | Monitoring |

**درسِ ملک‌طب:** آن‌جا ضریب‌ها و مبالغِ واحد در JS هاردکد شدند و هر تغییرِ تعرفه
یعنی دیپلوی. در عمل‌یار این‌ها **رکوردِ دیتابیس**اند (جدولِ `ServiceTariff`) و از
تنظیمات ویرایش می‌شوند.

## ۳. اجزای فاکتور

1. عنوانِ خدمت
2. مشخصاتِ ارائه‌دهنده — از تنظیماتِ برند (نام/نشانی/تلفن)، نه هاردکد
3. مشخصاتِ گیرنده — از خودِ `Visit`: بیمارستان، بیمار، جراح، تاریخِ عمل
4. جدولِ خدمات: ردیف | کدِ مراقبت | شرح | نوعِ سهم | ضریبِ تعرفه | ساعت | مبلغِ واحد | جمعِ کل
5. مالکِ دستگاه (شرکت / بیمارستان)
6. مبلغِ قابلِ پرداخت: عدد + **به‌حروفِ فارسی** با `numToWordsFa` از `src/lib/money.js`
7. توضیحات
8. امضاها

تاریخ‌ها با `isoToJStr` از `src/lib/jalali.js` نمایش داده می‌شوند؛ در DB همیشه ISO.

## ۴. چاپ — قواعدی که واقعاً می‌شکنند

این بخش گران‌ترین درسِ ملک‌طب است. **قبل از گفتنِ «انجام شد» روی هر سه محیط بسنج:
Android (Chrome)، iOS/macOS (Safari)، Windows (Chrome/Edge/Firefox).**

```css
@page { size: A4; margin: 0; }

/* بدونِ این، Safari و Chrome رنگ/گرادیان/سربرگ را چاپ نمی‌کنند */
.sheet, .sheet * {
  -webkit-print-color-adjust: exact;
  print-color-adjust: exact;
}

/* قفلِ صفحه — وگرنه Safari یک صفحهٔ دومِ سفید می‌سازد */
.sheet { width: 210mm; height: 297mm; overflow: hidden; position: relative; }

/* جدولِ بلند نباید وسطِ سطر بشکند */
tr, .sig-box { break-inside: avoid; page-break-inside: avoid; }
```

- **رادیو/چک‌باکس:** Safari وضعیتِ `checked` و `accent-color` را قابل‌اعتماد چاپ
  نمی‌کند. کنترل را با CSS بکش: `appearance:none` + نقطه/تیکِ ساخته‌شده با
  `border`/`background` + همان `print-color-adjust: exact`.
- **تیک با CSS در RTL:** بوردرِ **فیزیکی** (`border-right`/`border-bottom`)، نه
  منطقی — وگرنه قرینه می‌شود (قانون ۹).
- **فونت:** Vazirmatn باید محلی سرو شود، نه از CDN. `local()` اول، بعد فایلِ
  خودی، و فقط در نهایت CDN. (فایلِ فونتِ ملک‌طب ۲۱ بایتِ خراب است و عملاً
  همیشه به CDN می‌افتد — همان اشتباه را تکرار نکن.)
- **اعدادِ فارسی:** ورودی را با نرمال‌سازِ ارقام به انگلیسی تبدیل کن؛ نمایش با
  `fmtMoney` از `src/lib/money.js`.

## ۵. اتصال به داشبورد

از کارتِ مراجعه در `Dashboard.jsx` یک کنشِ «فاکتور» اضافه می‌شود که
`/app/invoices/new?visit=<id>` را باز می‌کند و فرم را با دادهٔ همان مراجعه
پیش‌پر می‌کند (بیمار، جراح، بیمارستان، تاریخ، مبلغ).

API پیشنهادی:

| متد | مسیر | کار |
|---|---|---|
| `GET` | `/invoices?visitId=` | فاکتورهای یک مراجعه |
| `POST` | `/invoices` | ساخت (سطرها از تعرفهٔ فعال پیش‌پر می‌شوند) |
| `PATCH` | `/invoices/:id` | ویرایش |
| `GET` | `/invoices/:id` | نسخهٔ غنی‌شده برای چاپ |

## ۶. دیباگِ سریع

| نشانه | علت معمول |
|---|---|
| محتوا از A4 بیرون می‌زند | `height: 297mm` + `overflow: hidden` روی `.sheet` نیست |
| صفحهٔ دومِ سفید در Safari | همان — ارتفاع قفل نشده |
| سربرگ/رنگ چاپ نمی‌شود | `print-color-adjust: exact` جا افتاده |
| تیکِ رادیو در چاپ نیست | کنترلِ native است، نه CSS-drawn |
| جدول وسطِ سطر می‌شکند | `break-inside: avoid` روی `tr` نیست |
| مبلغ غلط | فرمول در JSX رفته — باید در `enrich()` سرور باشد |
| فونت در چاپ عوض می‌شود | فونت از CDN می‌آید و در لحظهٔ چاپ لود نشده |
