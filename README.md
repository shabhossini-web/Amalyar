# عمل‌یار

SaaSِ مدیریتِ شرکت‌های خدمات و تجهیزاتِ جراحی — از پذیرشِ بیمار تا پس از عمل.
مالتی‌تننت (دیتابیس به‌ازای هر شرکت)، React + Vite روی NestJS + PostgreSQL.
