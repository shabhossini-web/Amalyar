# `.sync/` — کلیمِ ایجنت‌ها

هر ایجنت **دقیقاً یک فایل** این‌جا دارد و **فقط فایلِ خودش** را می‌نویسد.
به همین دلیل این پوشه هیچ‌وقت کانفلیکت نمی‌خورد — برخلافِ یک فایلِ مشترک که هر
دو طرف بالایش اضافه می‌کنند.

پروتکل در **`AGENTS.md`** ریشهٔ مخزن است. نگهبان: `node scripts/verify-claims.js`.

نامِ فایل باید با `agent:` داخلش یکی باشد. ایجنتِ تازه = یک فایلِ تازه با همین قالب.
