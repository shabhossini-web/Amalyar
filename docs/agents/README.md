# دستیارهای عملیار — قرارداد پیشنهادی توسعه

این پوشه بسته طراحی است. هیچ API، نقش کاربری، ایجنت فعال، مجوز Git یا گردش‌کار عملیاتی با اضافه‌شدن این فایل‌ها فعال نمی‌شود.

درخواست محصول: دستیار مرکزی بتواند ایجنت‌های تخصصی را تعریف و بازطراحی کند، مدل و ابزارهایشان را تغییر دهد و در محدوده اختیار واگذارشده دسترسی بدهد یا پس بگیرد. توسعه این بخش با همکاری Codex و Claude و مطابق پروتکل ریشه مخزن پیش برود.

مبنای بررسی جدید: `main@faff39da25726d2b67e802a70496abb9ecef4f03`، تاریخ ۲۰۲۶-۰۹-۱۲. تغییرات جدید ریشه، پروتکل `AGENTS.md`، فایل‌های `.sync/` و workflowهای همکاری را اضافه کرده‌اند. طرح اولیه معماری بر پایه نسخه محصول `31d0ff4` بوده و در فایل معماری حفظ شده است.

مرحله بعد: پیاده‌سازی یک برش عمودی کوچک «فهرست ایجنت‌ها + پیش‌نویس تعریف + نسخه‌ها + اعتبارسنجی و پیش‌نمایش تغییر» با ماتریس مجوز و UI استاندارد پروژه. فعال‌سازی ابزارهای مالی و اعطای خودکار مجوز، مراحل بعدی این برش هستند.

هیچ‌یک از نام‌های API و ابزارهای پیشنهادی در این پوشه قرارداد منتشرشده فعلی محصول نیست. آن‌ها باید هنگام شروع پیاده‌سازی، با کد موجود و مالک همان بخش تطبیق داده شوند.

شناسه‌های ابزار و اتصال مدل در نمونه‌ها پیشنهادی‌اند؛ `company-chat` یک نام نمونه است و وجود اتصال یا مجوزی را در نصب فعلی اثبات نمی‌کند.

## بررسی این بسته

- `npm run build` در ریشه و `server` موفق بود؛ source هر فایل لازم برای ساخت با Git blob hash مبنای `faff39d` تطبیق داده شد.
- اعتبارسنجی Draft-07 با Ajv: دو نمونه پذیرفته و ۱۵ ساختار نامعتبر رد شدند. این آزمون مجوز اجرایی یا امنیت runtime را اثبات نمی‌کند.
- `node scripts/verify-claims.js` موفق بود. هیچ مسیر محصولی تغییر نکرده و سناریوی UI/API تازه‌ای برای اجرای e2e وجود ندارد.
- هنگام آماده‌سازی، main با PR شماره ۷ به `69b90ff` رسید؛ تغییر آن فقط مستند وضعیت و claim کلاد بود. بسته از این مبنای تازه ساخته می‌شود.
