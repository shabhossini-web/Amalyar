این پوشه محلِ **هماهنگیِ ایجنت‌ها** برای پیاده‌سازیِ `docs/UX_WORKFLOW_AUDIT_2026-09-16.md` است.
ایجنت‌ها (Claude Fable، Claude Opus، GPT) هم‌دیگر را نمی‌بینند؛ تنها کانالِ مشترکشان همین
مخزن است. پس هر چیزی که یک ایجنت باید از دیگری بداند **باید در گیت باشد**، نه در چت.

| فایل | مالک | چه چیزی در آن است |
|---|---|---|
| `BOARD.md` | مالکِ محصول (ثابت) | تقسیمِ چهل بسته به سه لِین، ترتیب، وابستگی‌ها |
| `CONTRACTS.md` | هر کس که قراردادِ مشترک می‌سازد/عوض می‌کند | شکلِ داده و APIهایی که بیش از یک لِین به آن دست می‌زند (WorkItem، DomainEvent، `/work`، `forVisitId`، وضعیتِ سفارش، اسنپ‌شاتِ فرم، draft، dedupeKey) |
| `DECISIONS.md` | مالکِ محصول | شش تصمیمی که فقط او می‌گیرد، هرکدام با **پیش‌فرض** — ایجنت‌ها با پیش‌فرض جلو می‌روند تا وقتی خطِ «تصمیم:» پر شود |
| `lanes/<agent>.md` | فقط همان ایجنت | فهرستِ بسته‌های آن لِین با وضعیت و شمارهٔ کامیت — **هیچ ایجنتی فایلِ لِینِ دیگری را ویرایش نمی‌کند** |
| `BRIEF_GPT.md` | مالکِ محصول | متنِ آمادهٔ چسباندن برای شروعِ GPT |

## هر ایجنت، هر بار، به این ترتیب شروع می‌کند

```bash
git fetch origin && git log --oneline -15 origin/main
cat .sync/*.md                      # چه کسی روی چه مسیری است
cat docs/plan/DECISIONS.md          # تصمیمِ تازه‌ای آمده؟
cat docs/plan/lanes/<من>.md         # بستهٔ بعدیِ من
git diff origin/main -- docs/plan/CONTRACTS.md   # قراردادی عوض شده؟
```

## قواعدِ اجرا (خلاصهٔ AGENTS.md + بخش ۷ سندِ بازبینی)

1. **هر بسته = یک شاخه** (`agent/<id>` برای GPT، `claude/<id>` برای Claude) **= یک PR = مرجِ همان روز.** `automerge.yml` پس از سبزشدنِ `security-ci` مرج می‌کند. کارِ نیمه‌کاره روی `main` نمی‌رود.
2. **پیش از اولین ویرایش** کلیم در `.sync/<شناسه>.md` (`status: active`, `branch`, `paths`). پس از مرج `status: idle` + یک خط زیرِ «اخیراً لند شد».
3. **فقط مسیرهای لِینِ خودت.** اگر ناچار شدی فایلی خارج از لِین را دست بزنی: اول در `.sync` خودت زیرِ «قراردادهایی که شکستم» بنویس، بعد کوچک‌ترین تغییرِ ممکن.
4. **`schema.prisma` فقط از تهِ فایل**؛ migration با `migrate diff`؛ هر مدلِ تازه tenant-safe و permission-aware (قانونِ ۴ `CLAUDE.md`).
5. **هر بسته یک e2e** در `scripts/e2e/<id>.mjs` که سناریوی «باید بیفتد» **و** «نباید بیفتد» را دارد.
6. **قراردادِ مشترک را عوض کردی؟** `CONTRACTS.md` را در همان PR به‌روز کن + یک خط در `.sync` خودت. مصرف‌کننده‌ها با `git diff` می‌فهمند.
7. **سؤالی داری که فقط مالک جواب می‌دهد؟** در `.sync` خودت زیرِ «سؤال از مالک» بنویس و در چت هم بگو. با پیش‌فرضِ `DECISIONS.md` ادامه بده؛ نایست.
8. **تمام‌شدن** = معیارِ پذیرشِ جدولِ بخش ۵ سندِ بازبینی + CI سبز + e2e + یک خط در `STATUS.md` (فقط تهِ فایل) + وضعیتِ ✅ با هش در `lanes/<من>.md`.
